# Air Quality data

`AirQualityUCI.csv` is the unmodified CSV used in the original project. It uses semicolon separators and decimal commas. The original parsing reads 9,471 rows including trailing empty rows, then 9,357 dated observations; complete-case filtering retains 6,941 rows. These counts describe this file, rather than substituting the catalogue's instance count.

**Citation:** Vito, S. (2008). *Air Quality* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C59K5F.

**Source:** https://archive.ics.uci.edu/dataset/360/air+quality
